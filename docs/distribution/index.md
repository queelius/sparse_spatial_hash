# Distribution & Community

Information about distributing, installing, and promoting the sparse_spatial_hash library.

## Package Managers

The library is available through multiple package managers for easy installation:

- **[vcpkg](package-managers.md#vcpkg)** - Microsoft's C++ package manager (available now)
- **[CMake FetchContent](package-managers.md#cmake-fetchcontent)** - Direct from GitHub
- **[Manual Installation](package-managers.md#manual)** - Copy headers directly

[View Installation Guide](package-managers.md){ .md-button .md-button--primary }
